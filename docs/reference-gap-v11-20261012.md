## 候选比较与选定方案

1. **仅增加顿帧/震屏/火花**：没有解决下劈却挑飞、下降追击不能延续的机制矛盾，暂不选。
2. **统一末段上行姿态、碰撞轨迹、状态反应，并记录命中前后物理量**：范围小，可独立V11试玩，沿用已有时间轴和保护，选定。
3. **重写浮空保护/衰减/落地起身策略**：可靠当前手游依据不足，风险更大，后续研究后再选。

实现：新增`CombatJuggle`/`drawJuggle`、生成器、独立V11页面和6项Node/10项候选浏览器检查。共享V9/V10只抽取默认等价的垂直反应/姿态入口；V10默认绘制与事件逐步回归一致，原smoke文件及5计数断言保持不变。新增手动V11 comparison workflow先跑原V10五断言，再跑候选，不替换旧工作流。

速度是**原创原型起始约束**，不是DNF参数：`g*(当前后摇+下一刀起手+下一刀有效期+一个物理步)/2`，对应从地面起飞可供下一次输入接触的弹道窗口；默认三刀最低续接速度3.8867、4.6017、4.6567。上升目标加相同增量但用原有上挑速度10.5封顶，下落目标至少达到该最低值。实际碰撞、水平位置、重力、hitstop仍决定是否连得上；不硬编码到点落地。

风险：过强续接可能造成反复低跳、目标逃出刀轨迹；最低速度边界可能显得一致/机械；真正人体旋转盒、逐帧sweep、攻击者位移未改。需要看真实V11视频验证，不能以153项逻辑通过宣布优化完成。
