## 代码结构与继承边界

- `prototype/combat-duel.mjs`：二角色各自持有既有V3 `CombatArena` 和V5动作控制器；中央固定1/120秒推进一次身体与动作时钟。V6控制器只替换V4的一次命中入口为有效段逐步碰撞检测，V3/V4/V5源码与旧测试保持原样。
- `prototype/duel-lab.template.html`：A青石/B赤砂原创几何角色，双方技能、步进移动、格挡开关、血条、攻击盒、暂停/单步/扫地演示。移动是每次按键0.2世界单位的实验操作，尚无完整摇杆、人物帧动画、音效或震屏。
- `prototype/build-duel-lab.mjs`：直接从四份已测试模块生成离线单文件 `duel-lab-v6.html`，避免手工维护源码副本。生成物和模块一致性由自动测试核验。
- `tests/combat-duel.test.mjs`、`tests/duel-page.test.mjs`、`tests/duel-lab-smoke.cjs`、`tests/run-v6-batch.mjs`：逻辑回归、源码一致性、待执行的Chromium交互、独立检查批量执行。

## 原创设计规则（非官方DNF参数）

| 规则 | V6行为 |
|---|---|
| HP/伤害 | 每人200HP；上挑18、空追10、扫地8、高位斩14；扣至0败北，不能再输入 |
| 动作时序 | 沿用V4四技能前摇/有效段/后摇；每个固定步在active检查当前盒，前摇/后摇没有攻击盒 |
| 技能独立盒 | 默认各技能沿用V3不同高度盒；支持多个盒及active归一化区间 `[from,to)`，按角色世界坐标和朝向镜像 |
| 连续窗口 | 有效段开始未命中时可在后续步首次接触命中；每次动作对同一目标至多一次成功接触，格挡也消费该次接触 |
| 命中节奏 | 保留V3 90ms闸门。状态/距离/节奏拒绝不扣血；在有效段尚未结束时允许后续步重试 |
| 格挡 | 站立、无动作/硬直时开启；仅挡正面，0削血，无连击计数/顿帧；背面无法挡。不含体力、破防、完美格挡 |
| 普通受击 | 扣血、动作打断、清输入缓冲；原型站立硬直0.18秒。浮空/倒地不能发动攻击 |
| 霸体 | 沿用上挑active霸体；仍扣全额HP、计保护，普通攻击不打断、不改身体动作反应；不是免伤/减伤 |
| 强制打断 | 技能配置 `force:true` 覆盖霸体；默认技能均false。测试包含配置覆盖；页面没有额外强制技能 |
| 保护优先 | 达阈值该次照常扣血，立即起身、打断动作、清硬直，保留原0.6秒无敌；保护覆盖霸体 |
| 顿帧 | 原40ms实验值；身体/受击动作冻结，双边开启时攻击动作时钟也暂停；保护起身清顿帧。固定步量化，不宣称设备实测40ms |
| 同步接触 | 同步长先收集双方接触意图，再结算，允许换血及同帧双败北；无服务器或网络语义 |

浮空4次/扫地3次/总7次、重力22、上挑10.5、空追5.5、倒地0.9秒、可选反弹等原实验规则由V3继承。本轮没有改这些参数，也没有把它们认定为官方规则。
