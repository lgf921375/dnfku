## 新增内容（原创设计值）

| 内容 | 实现与边界 |
|---|---|
| 持剑人物 | `scroll-renderer.mjs` 原创Canvas关节/多边形人物，肩臂/剑/腿/披风；站立呼吸、行走、前摇蓄势、挥砍、后摇回收、受击后仰、浮空及倒地。不使用官方或第三方素材；不是正式美术帧动画 |
| 横版舞台 | 废墟拱廊、透视地面、阴影、相机随横向位置移动；横屏优先界面，血条顶部、摇杆左下、技能右下；竖屏兼容布局代码已写，但浏览器尚未验收 |
| 连续摇杆 | 每固定步读取输入，横移3.6世界单位/秒；前后走位1.9单位/秒，范围±1.2；输入归一化、松手/失焦/隐藏清输入；实际多指仍待浏览器与手机测试 |
| 前后走位判定 | 与浮空Y轴独立的lane字段；两角色lane差大于0.55时不命中。是V7原创场景扩展，非官方DNF判定 |
| 命中反馈 | 有效命中产生火花、数字、短时受击亮色与轻震屏；普通受击新增水平击退初速1.7、上挑0.7，指数衰减14；顿帧中击退暂停，霸体/保护不新增击退 |
| 攻击操作 | 攻击键依目标状态选择高位斩/落地扫地，按住重复输入并沿用原缓冲；独立上挑、空追、扫地键；格挡按住开启、释放结束 |
| 陪练 | 默认关闭、可启用单敌简易靠近/攻击。不是复杂怪物AI，也不改其他游戏的怪物规则 |
| 音效 | 默认关闭，用户点击开启后用WebAudio合成短促命中/格挡音；没有第三方声音文件。真实音频播放未覆盖 |
| 结束状态 | 败北显示结果与重来按钮；没有自动复活、正式关卡或进度系统 |

V3的重力22、上挑10.5、浮空4次/扫地3次/总7次保护、保护无敌0.6秒、90ms闸门，以及V4前摇/有效/后摇、V5取消/霸体和V6扣血/格挡保持原样。**没有靠改保护阈值冒称改善手感。**
